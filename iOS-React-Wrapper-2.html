iOS React Native Wrapper

Integrate IDmission's IDentity SDK into your iOS React Native application.

Prerequisites

  • React Native 0.83 or later (bare workflow or a custom dev client — not Expo Go) — React Native environment setup →
  • Node 20 or later
  • iOS deployment target 15.6 and a recent Xcode
  • CocoaPods plus the cocoapods-user-defined-build-types gem
  • A physical iOS device — the simulator does not support camera capture

Setup

  1. 1

    Install the module directly from GitHub with npm. No Google Drive download is required — the native module is autolinked.

    Shell
    npm install git+https://github.com/Idmission-LLC/react-native-idmission-sdk.git#v11.1.13
    The #v11.1.13 suffix pins the install to the release tag. Do not track main.
  2. 2

    Set up CocoaPods. Install the build-types plugin, update ios/Podfile (replace YourAppName with your target's name), then install the pods.

    Shell
    sudo gem install cocoapods-user-defined-build-types
    ios/Podfile
    plugin 'cocoapods-user-defined-build-types'

enable_user_defined_build_types!

require Pod::Executable.execute_command('node', ['-p',
  'require.resolve(
    "react-native/scripts/react_native_pods.rb",
    {paths: [process.argv[1]]},
  )', __dir__]).strip

platform :ios, '15.6'
prepare_react_native_project!

target 'YourAppName' do
  config = use_native_modules!

  pod 'IDentityMediumSDK2.0'
  pod 'GoogleMLKit/TextRecognition', :build_type => :dynamic_framework

  use_react_native!(
    :path => config[:reactNativePath],
    :app_path => "#{Pod::Config.instance.installation_root}/.."
  )

  post_install do |installer|
    react_native_post_install(
      installer,
      config[:reactNativePath],
      :mac_catalyst_enabled => false
    )
  end
end
    Shell
    cd ios
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 pod install
cd ..
    GZIP and GoogleMLKit/TextRecognition must be linked as :dynamic_framework (enabled by the cocoapods-user-defined-build-types plugin), or you will hit linker errors. The LANG / LC_ALL prefixes avoid the CocoaPods Unicode Normalization error on non-UTF-8 terminals.
  3. 3

    Add the required camera, microphone, and photo-library permission strings to ios/YourAppName/Info.plist. A missing key causes an immediate crash on iOS 14+.

    Info.plist
    <key>NSCameraUsageDescription</key>
<string>Camera access is required to capture identity documents and verify your face.</string>

<key>NSMicrophoneUsageDescription</key>
<string>Microphone access may be required during identity verification.</string>

<key>NSPhotoLibraryUsageDescription</key>
<string>Photo library access is required to select identity documents for verification.</string>
  4. 4

    Build and run on a physical device.

    Shell
    npm run ios
    The IDentity SDK requires a physical device — the iOS Simulator does not support camera capture and will not run the SDK flows.

Available Functions

Import the module and follow this pattern. Results for every call are delivered asynchronously through the DataCallback event.

JavaScript — usage pattern
import { IDMissionSDK, addDataCallbackListener } from 'react-native-idmission-sdk';

// 1. Subscribe to results (init, services, and submit all emit here)
const subscription = addDataCallbackListener((event) => {
  console.log('IDmission result:', event.data);
});

// 2. Initialise once before calling any service
IDMissionSDK.initializeSDK(apiBaseUrl, authUrl, debug, accessToken);

// 3. Call a service
IDMissionSDK.serviceID10();

// 4. Submit the result
IDMissionSDK.submitResult();

// 5. Clean up when done
subscription.remove();
InitIDMissionSDK.initializeSDK

Initializes the SDK. Must be called before any other function.

JavaScript
IDMissionSDK.initializeSDK(
  apiBaseUrl,   // string — API base URL, provided by IDmission
  authUrl,      // string — auth URL, provided by IDmission
  debug,        // string — 'y' enables verbose logging, 'n' disables it
  accessToken   // string — your IDmission access token
);
ServiceIDMissionSDK.serviceID20

Initiates the ID Validation (Service ID 20) flow. Captures and validates a government-issued ID document.

JavaScript
IDMissionSDK.serviceID20();
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID10

Initiates the ID Validation and Match Face (Service ID 10) flow. Captures an ID document and matches a live selfie to the photo on the ID.

JavaScript
IDMissionSDK.serviceID10();
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID185

Initiates the Identify Customer (Service ID 185) flow.

JavaScript
IDMissionSDK.serviceID185();
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID660

Initiates the Live Face Check (Service ID 660) flow. Performs liveness detection without document capture.

JavaScript
IDMissionSDK.serviceID660();
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID50

Initiates the ID Validation and Customer Enroll (Service ID 50) flow. Pass your unique customer number.

JavaScript
IDMissionSDK.serviceID50(uniqueCustomerNumber); // string
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID175

Initiates the Customer Enroll Biometrics (Service ID 175) flow.

JavaScript
IDMissionSDK.serviceID175(uniqueCustomerNumber); // string
IDMissionSDK.submitResult();
ServiceIDMissionSDK.serviceID105

Initiates the Customer Verification (Service ID 105) flow.

JavaScript
IDMissionSDK.serviceID105(uniqueCustomerNumber); // string
IDMissionSDK.submitResult();
SubmitIDMissionSDK.submitResult

Submits the captured data and finalizes the current service flow. Call after every service.

JavaScript
IDMissionSDK.submitResult();
